z88dk for WebAssembly: what these files are, and their licences
================================================================

The .mjs and .wasm files here are programs built with Emscripten; the .tar
packs hold files from a built z88dk. Each comes from one of these:

z88dk (zcc, z88dk-ucpp, z88dk-zpragma, z88dk-sccz80, z88dk-copt, z88dk-z80asm,
and the libraries, headers and start-up code in the packs)
    The Clarified Artistic License (and, for some files, the licence the file
    itself states): https://github.com/z88dk/z88dk/blob/master/LICENSE
    Built from z88dk's sources (https://github.com/z88dk/z88dk) with the
    build in the wasm/ directory of the fork that carries it
    (https://github.com/mirage2032/wasm-z88dk, branch wasm), which changes
    nothing in them; the one difference from a native build is that
    z80asm's parser (the generated src/z80asm/src/c/parse_rules.h) is
    compiled with most of its actions dispatched from a table instead of a
    switch (wasm/parse_actions.mjs), so that browsers can optimise it. It
    behaves the same.

GNU m4 1.4.19 (m4)
    GNU General Public License, version 3 or later:
    https://www.gnu.org/licenses/gpl-3.0.html
    Built, unmodified, from the release m4-1.4.19.tar.xz, which is next to
    this file: its corresponding source. Also at
    https://ftp.gnu.org/gnu/m4/m4-1.4.19.tar.xz
    Built with Emscripten 6.0.11, in the unpacked release, by these commands
    (the wasm/ directory's Makefile runs the same):
        emconfigure ./configure --build=$(sh build-aux/config.guess) \
            --host=wasm32-unknown-emscripten --disable-nls \
            --disable-threads --without-libsigsegv --disable-assert \
            CFLAGS="-O2 -ffile-prefix-map=$PWD/=" \
            CPPFLAGS="-include stddef.h"
        emmake make -C lib
        emmake make -C src m4
        emcc -O2 -sMODULARIZE=1 -sEXPORT_ES6=1 -sENVIRONMENT=web,worker \
            -sWASM_ASYNC_COMPILATION=0 -sALLOW_MEMORY_GROWTH=1 \
            -sMAXIMUM_MEMORY=128MB -sSTACK_SIZE=4MB -sEXIT_RUNTIME=1 \
            -sFORCE_FILESYSTEM=1 -lproxyfs.js \
            -sEXPORTED_RUNTIME_METHODS=FS,PROXYFS,ENV \
            -sINCOMING_MODULE_JS_API=arguments,thisProgram,preRun,print,printErr,stdin,wasmBinary,onExit,onAbort,noInitialRun \
            -o m4.mjs src/*.o lib/libm4.a
